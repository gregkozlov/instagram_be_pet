модуль содержит в себе контроллер и сервис
контроллер принимает запрос с фронта и возвращает ответ
сервис выполняет функции тригернутые контроллером

nest g module users - создает модуль юзеров
nest g controller users - создает контроллер юзеров
nest g service users - создает сервис юзеров

nest g resource users - создает все перечисленное выше + DTO
